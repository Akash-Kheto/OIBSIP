## 📂 Projects Overview

### 🌐 Level 1 — Web Development Projects

#### Task 1: Landing Page

A visually appealing landing page designed with a clean layout, attractive sections, and responsive styling.

**Key Features:**

* Attractive hero section
* Multiple content sections
* Modern UI design
* Responsive layout

#### Task 2: Personal Portfolio

A personal portfolio website showcasing my profile, skills, education, projects, and contact information.

**Key Features:**

* About Me section
* Skills and education
* Project showcase
* Contact section
* Responsive design

#### Task 3: Temperature Converter Website

A temperature conversion website that converts values between Celsius, Fahrenheit, and Kelvin.

**Key Features:**

* Temperature input
* Multiple conversion units
* Instant conversion results
* Input validation
* User-friendly interface

---

### 💻 Level 2 — Interactive Web Applications

#### Task 1: Calculator

A functional calculator built using HTML, CSS, and JavaScript to perform basic arithmetic operations.

**Key Features:**

* Addition, subtraction, multiplication, and division
* Clear and delete functionality
* Interactive buttons
* Responsive layout

#### Task 2: Tribute Page

A tribute webpage dedicated to an inspiring personality, highlighting their life, achievements, and contributions.

**Key Features:**

* Prominent subject image
* Biography and achievements
* Timeline or important milestones
* Clean and engaging design

#### Task 3: To-Do Web App

An interactive task management application to organize daily activities.

**Key Features:**

* Add new tasks
* Edit existing tasks
* Mark tasks as completed
* Delete tasks
* Separate pending and completed tasks

#### Task 4: Login Authentication System

A login and registration application demonstrating user authentication concepts.

**Key Features:**

* User registration and login interface
* Form validation
* Password input handling
* Login and logout functionality
* Authentication and session handling, where implemented

> **Security Note:** Client-side validation or Local Storage alone does not provide secure authentication. Production applications should use a secure backend and appropriate password hashing.

## ▶️ How to Run the Projects

1. Clone this repository:

   ```bash
   git clone https://github.com/Akash-Kheto/OIBSIP.git
   ```

2. Open the project folder:

   ```bash
   cd OIBSIP
   ```

3. Open the required task folder.

4. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.

5. Explore and test the project features.

*Projects requiring a backend may need additional setup.*
