## 📌 About the Project

The **Tribute Page** is a frontend web development project built as part of the **Oasis Infobyte Internship (OIBSIP) — Web Development and Designing, Level 2, Task 2**.

The website is designed to honor an inspiring historical figure, scientist, artist, or public personality. It presents their biography, achievements, milestones, and memorable quotes through an attractive and responsive user interface.

> 💡 **Project Goal:** Transform a person's inspiring journey into an engaging digital storytelling experience using HTML5 and CSS3.

## 🎯 Objectives

* Build a visually appealing and accessible webpage.
* Present a subject's life story through original written content.
* Highlight important milestones with a timeline or achievement cards.
* Display a meaningful quotation in a distinctive layout.
* Explore typography, colour contrast, spacing, and visual hierarchy.
* Create a responsive experience for desktop, tablet, and mobile users.

## ✨ Features

| Feature              | Description                                             |

| 👤 Hero Section      | Subject's name, introduction, and tagline               |

| 🎨 Modern UI         | Multiple background colours and elegant typography      |

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/Akash-Kheto/OIBSIP.git
```

### 2. Navigate to the Project Directory

```bash
cd OIBSIP/L2/Task-2-Tribute-Page
```

### 3. Launch the Website

Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.

### 4. Explore the Code

Edit `index.html` to update the tribute content and `style.css` to customize the appearance.
