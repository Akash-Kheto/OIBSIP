# 🌟 Tribute Page

A visually engaging and responsive tribute webpage dedicated to an inspiring historical figure, scientist, artist, or public personality.

## 📌 Project Overview

The **Tribute Page** is a web development project created as part of the **Oasis Infobyte Internship (OIBSIP) – Web Development and Designing, Level 2, Task 2**.

The objective of this project is to design a beautiful and informative webpage that celebrates the life, achievements, contributions, and legacy of an admired personality using HTML5 and CSS3.

## 🎯 Objectives

* Create an attractive and well-structured tribute webpage.
* Present the subject's biography and important life events.
* Highlight key achievements through a timeline or styled cards.
* Display a meaningful quote in a distinctive design.
* Practice responsive web design and modern CSS styling.
* Improve HTML semantic structure and typography.

## ✨ Features

* **Subject Introduction:** A page title featuring the subject's name and a memorable tagline.
* **Prominent Image:** A relevant, royalty-free image sourced from Unsplash or Wikimedia Commons.
* **Biography Section:** At least 3–4 paragraphs of original tribute content.
* **Timeline of Achievements:** An ordered list or styled cards highlighting important milestones.
* **Inspirational Quote:** A dedicated quote block featuring a notable quotation from or about the subject.
* **Modern Design:** Multiple background colours and visually appealing section layouts.
* **Typography:** A combination of serif headings and sans-serif body text.
* **Responsive Layout:** A flexible design for desktop, tablet, and mobile devices.
* **Clean Code:** Well-organized HTML and CSS for readability and maintainability.
