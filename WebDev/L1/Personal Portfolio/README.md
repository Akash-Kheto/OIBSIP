## 📌 Project Overview

The **Personal Portfolio Website** is Task 2 of Level 1 in my Oasis Infobyte (OIBSIP) Web Development and Designing Internship.

The objective is to create a personal website that presents my background, technical skills, projects, and contact information in a professional and organized way. It serves as my digital résumé and helps visitors explore my work and connect with me.

## 🎯 Objectives

* Build a professional online identity.
* Showcase technical skills and projects.
* Present educational background and career interests.
* Provide accessible contact and social profile links.
* Create a responsive interface for desktop, tablet, and mobile devices.

## 🚀 How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Akash-Kheto/OIBSIP.git
   ```

2. Navigate to the repository folder:

   ```bash
   cd OIBSIP
   ```

3. Open `L2-Personal-Portfolio` in VS Code.

4. Open `index.html` in your browser or launch it using the Live Server extension.

No additional dependencies are required for a basic HTML/CSS portfolio.

## 📱 Responsive Design

The website should adapt to different screen sizes:

* **Desktop:** Spacious layouts and clear content sections.
* **Tablet:** Flexible grids and balanced spacing.
* **Mobile:** Readable text, touch-friendly links, and vertically stacked content.

CSS media queries, Flexbox, and Grid can help achieve responsiveness.
