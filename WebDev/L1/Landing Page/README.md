## 📌 Project Overview

The **Landing Page** is Task 1 of Level 1 in my Oasis Infobyte (OIBSIP) Web Development and Designing Internship.

The objective of this project is to build a visually polished static landing page for a product, service, or brand. This project focuses on strengthening foundational frontend development skills through semantic HTML, modern CSS layouts, typography, spacing, and responsive design.

## 🎯 Objective

* Create a visually appealing landing page.
* Practice semantic HTML5 elements.
* Apply CSS3 styling, Flexbox, and Grid where appropriate.
* Build a clear navigation and call-to-action section.
* Maintain consistent colors, typography, padding, and margins.
* Ensure the layout works across desktop, tablet, and mobile screens.

## 🛠️ Tech Stack

| Technology | Purpose                                      |
| ---------- | -------------------------------------------- |
| HTML5      | Structure and semantic content               |
| CSS3       | Styling, layouts, colors, and responsiveness |

**Note:** JavaScript is not required for this task.

## ✨ Feature Checklist

* [ ] Fixed or sticky navigation bar with at least three navigation links
* [ ] Hero section with headline, subheadline, and call-to-action button
* [ ] At least two distinct content sections, such as Features and About
* [ ] Footer with placeholder contact and social links
* [ ] Consistent color palette across all sections
* [ ] Responsive layout using CSS Flexbox or Grid
* [ ] No element overlap or unintended overflow
* [ ] Intentional padding, margins, and `box-sizing`
* [ ] Readable typography with different heading and body font sizes

> Update the checklist by replacing `[ ]` with `[x]` as you complete and verify each feature.

## 🚀 How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/Akash-Kheto/OIBSIP.git
   ```

2. Navigate to the Landing Page folder:

   ```bash
   cd OIBSIP
   ```

3. Open the `L1-Landing-Page` folder in VS Code.

4. Open `index.html` in your browser, or use the Live Server extension.

## 📱 Responsive Design

The landing page should be tested at different viewport widths:

* **Desktop:** Full navigation and multi-column layouts where appropriate.
* **Tablet:** Adjusted spacing and flexible content sections.
* **Mobile:** Readable text, appropriately sized buttons, and no horizontal overflow.
