## 🚀 How to Run the Projects

1. Clone this repository:

   ```bash
   git clone https://github.com/Akash-Kheto/OIBSIP.git
   ```

2. Open the project folder:

   ```bash
   cd OIBSIP
   ```

3. Open the folder of the project you want to explore.

4. Open its `index.html` file in your browser, or use the **Live Server** extension in VS Code.

5. For projects that require JavaScript, make sure the script file is correctly linked in the HTML.

> These instructions apply to the standalone frontend projects. If a project later requires a backend, follow the setup instructions in that project's own README.
