## 🚀 How to Run the Projects

### Frontend Projects

1. Clone this repository:

   ```bash
   git clone https://github.com/Akash-Kheto/OIBSIP.git
   ```

2. Open the repository:

   ```bash
   cd OIBSIP
   ```

3. Open the required project folder.

4. Open `index.html` in your browser or use the VS Code Live Server extension.

### Full-Stack Authentication Project

If your authentication project uses Node.js and Express:

1. Open the authentication project directory.

2. Install the dependencies:

   ```bash
   npm install
   ```

3. Configure the required environment variables.

4. Start the server using the command defined in that project's `package.json`.
